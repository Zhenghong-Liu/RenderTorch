12.2 · 光如何变成颜色

从几何法线到材质响应

几何决定表面朝向，光源决定能量从哪个方向射来，材质决定有多少能量被吸收、散射或反射。 渲染器把这些信息压缩成一个着色计算：给定表面点、法线、光源方向和观察方向，输出颜色。

本章先学习两个可分解、可验证的模型：Lambert 漫反射与 Blinn–Phong 高光。 它们足以解释“迎着光更亮、侧面更暗、光滑表面出现亮斑”，也适合作为理解真实 PBR 的入口。

12.3 · 符号与定义

方向、材质与半向量

在世界空间或统一的着色空间中，定义：

  • \(\mathbf N\)：单位表面法线；
  • \(\mathbf L\)：从表面点指向光源的单位方向；
  • \(\mathbf V\)：从表面点指向观察者的单位方向；
  • \(\mathbf H=\operatorname{normalize}(\mathbf L+\mathbf V)\)：半向量；
  • \(\mathbf C_{\mathrm{base}}\)：基础颜色，也称 albedo；
  • \(k_a,k_d,k_s\)：环境光、漫反射、高光权重；
  • \(s\)：高光指数，越大亮斑越集中。

点积 \(\mathbf N\cdot\mathbf L\) 是入射方向与法线夹角的余弦。 当它为负，光源位于表面背侧，该光源不应贡献漫反射。 所有进入点积的方向都应先归一化，否则结果会随向量长度改变。

12.4 · 逐步推导

Lambert 与 Blinn–Phong

第一步：Lambert 余弦定律。 单位面积接收到的光通量与入射角余弦成正比， 因此漫反射项为：

\[I_{\mathrm{diffuse}}=k_d\,\mathbf C_{\mathrm{base}}\, \max(0,\mathbf N\cdot\mathbf L).\]

代码中对应 diffuse = max(0, N · L)。这里的 max 同时完成背面光源剔除， 不应改成绝对值，否则背面会被错误照亮。

第二步：高光半向量。 观察方向 \(\mathbf V\) 与光源方向 \(\mathbf L\) 关于法线对称时， 镜面反射光最可能进入眼睛。两者的平均方向为：

\[\mathbf H=\operatorname{normalize}(\mathbf L+\mathbf V).\]

代码中对应 H = normalize(L + V)。若 \(\mathbf L+\mathbf V\) 接近零，半向量没有稳定方向，应将高光置零。

第三步：经验高光。 Blinn–Phong 用法线与半向量的点积控制亮斑：

\[I_{\mathrm{specular}}=k_s\,\mathbf C_{\mathrm{spec}}\, [\max(0,\mathbf N\cdot\mathbf H)]^s.\]

第四步：合成。 在线性颜色空间中：

\[\mathbf C_{\mathrm{linear}}=k_a\mathbf C_{\mathrm{base}}+ k_d\mathbf C_{\mathrm{base}}\max(0,\mathbf N\cdot\mathbf L)+ k_s\mathbf C_{\mathrm{spec}}[\max(0,\mathbf N\cdot\mathbf H)]^s.\]

第五步：走向 PBR。 真实微表面模型把高光拆成 Fresnel、微表面分布和几何遮挡， 并用粗糙度控制分布宽度、用金属度控制基础反射颜色。Blinn–Phong 是经验模型，不等于 PBR； 它的优势是简单、稳定、容易逐项调试。

12.5 · 数值算例

一个方向明确的着色样本

取 \(\mathbf N=(0,0,1)\)、\(\mathbf V=(0,0,1)\)、 \(\mathbf L=(0.6,0,0.8)\)，基础颜色 \((0.6,0.2,0.1)\)， 参数 \(k_a=0.1,k_d=0.8,k_s=0.5,s=16\)。

漫反射因子为 \(\max(0,0.8)=0.8\)。半向量为 \(\mathbf H=\operatorname{normalize}((0.6,0,1.8))\approx(0.316,0,0.949)\)， 所以 \(\mathbf N\cdot\mathbf H\approx0.949\)，高光强度约为 \(0.5(0.949)^{16}\approx0.214\)。

\[\begin{aligned} \mathbf C_{\mathrm{ambient}}&=(0.060,0.020,0.010),\\ \mathbf C_{\mathrm{diffuse}}&=0.8(0.6,0.2,0.1)(0.8)=(0.384,0.128,0.064),\\ \mathbf C_{\mathrm{specular}}&=(0.214,0.214,0.214),\\ \mathbf C_{\mathrm{linear}}&\approx(0.658,0.363,0.288). \end{aligned}\]

若暂时直接映射到 8 位显示，结果约为 \((168,92,74)\)。 第 14 章会说明为什么正式管线应先在线性空间计算，再做 gamma 与色调映射。

12.6 · 伪代码与源码映射

逐项计算再相加

JAVASCRIPT · 概念伪代码
const diffuse = Math.max(0, dot(N, L));
const halfSum = add(L, V);
const H = length(halfSum) > 1e-12 ? scale(halfSum, 1 / length(halfSum)) : null;
const specular = H ? Math.pow(Math.max(0, dot(N, H)), shininess) : 0;
const ambient = scale(baseColor, ambientStrength);
const diffuseColor = scale(baseColor, diffuseStrength * diffuse);
const specularColor = scale(specularColorBase, specularStrength * specular);
const linear = clamp(add(add(ambient, diffuseColor), specularColor), 0, 1);

RenderTorch 的 _shade 只按整个三角形计算一次法线， 使用 abs(N·L) 生成明暗，并把结果乘以材质颜色。 它没有逐像素法线、观察方向、独立高光项或粗糙度参数。

12.7 · 自测

方向、贡献与模型边界

问题 1：为什么漫反射使用 max(0,N·L)，而不是 abs(N·L)？

答案：背侧光源不应照亮单面材质；abs 会把背面错误地变亮。

问题 2：高光指数增大时亮斑如何变化？

答案：点积小于 1 时，幂次越高数值越小，因此亮斑更窄、更集中。

问题 3：Blinn–Phong 是 PBR 吗？

答案：不是。它是经验着色模型；PBR 还需要微表面、Fresnel、能量守恒等更完整的描述。

问题 4：金属度升高时基础颜色通常怎样变化？

答案：金属的漫反射很弱，彩色反射主要由基础反射颜色决定；非金属则保留较强漫反射。

12.8 · 常见错误与调试

过亮球体与不稳定高光

  1. 整个表面发白：检查各贡献是否在线性空间相加，以及最终是否过晚 clamp。
  2. 法线长度导致亮度变化：进入点积前归一化 N、L、V。
  3. 高光在球面上游走：确认 L 与 V 都指向表面外，且使用同一个坐标空间。
  4. 背面发亮：漫反射误用了 abs，或未统一面绕序。
  5. 亮斑突然消失：检查 L+V 是否接近零，以及 shininess 是否过大造成数值下溢。

调试时先关闭高光只验证漫反射，再单独验证半向量，最后合成三项。

12.9 · 实现状态

当前逐面着色与后续材质路线

浏览器概念实验 本章绘制逐像素着色球体， 显示样本点的 N、L、V 与环境光、漫反射、高光和最终 RGB。

现有 RenderTorch renderer/pipeline.py 使用固定方向光与逐面叉积法线，强度为 0.5 + 0.5 * abs(N·L)。 材质目前主要提供 RGBA 基础颜色。

后续实现路线 最小升级顺序是： 世界空间点积与观察方向 → 顶点法线插值 → 漫反射/高光分解 → 线性颜色输出。 完整 PBR 还需要材质系统、粗糙度、金属度、Fresnel 与微表面模型。
