10.2 · 把连续三角形交给离散像素

光栅化就是判断哪些像素中心被覆盖

经过投影和视口变换，三角形已经成为屏幕上的三个二维点。 但屏幕并不是连续画布，而是由有限像素组成。渲染器必须决定： 某个像素要不要写入这个三角形，以及写入时使用哪些顶点属性。

齐次裁剪负责先去掉视锥外的部分，透视除法负责把裁剪空间变成 NDC。 只有完成这两步，边函数才能在正常的二维屏幕坐标中工作。 若相机背后的顶点直接除以 \(w\)，投影位置会被错误反射或发散，三角形可能连接错误的屏幕区域。

10.3 · 符号与定义

齐次裁剪平面与边函数

设裁剪空间点为 \(\mathbf q=(x_c,y_c,z_c,w_c)\)。 在除以 \(w_c\) 之前，六个裁剪平面要求：

\[\begin{aligned} -w_c&\le x_c\le w_c,&-w_c&\le y_c\le w_c,\\ -w_c&\le z_c\le w_c,&w_c&>0. \end{aligned}\]

最后一条保证透视除数有效。near 平面对应 \(z_c+w_c\ge0\)， 因此相机后方或穿过近平面的几何必须先被裁掉。

对屏幕二维点，定义边函数：

\[E(a,b,p)=(p_x-a_x)(b_y-a_y)-(p_y-a_y)(b_x-a_x).\]

它等于有向面积的两倍，也等于二维叉积的相反数。 对同一个三角形，三条边函数使用同一个面积作分母时，符号会相互抵消， 因此不必强行让某一种顶点顺序产生正面积。

10.4 · 逐步推导

从裁剪平面到重心坐标

第一步：齐次裁剪。 对每条线段或每个多边形边， 计算两端到裁剪平面的有符号距离。若两端都在外部，整段丢弃； 若一内一外，在齐次坐标中求交点：

\[t=\frac{d_{\mathrm{prev}}}{d_{\mathrm{prev}}-d_{\mathrm{cur}}},\qquad \mathbf q_{\mathrm{hit}}=\mathbf q_{\mathrm{prev}}+ t(\mathbf q_{\mathrm{cur}}-\mathbf q_{\mathrm{prev}}).\]

不能先在 NDC 中裁剪，因为除以 \(w\) 会丢失齐次空间中的直线关系。 裁剪完成后，每个顶点的 \(w\) 都应为正，再执行 \((x_{\mathrm{ndc}},y_{\mathrm{ndc}},z_{\mathrm{ndc}})=(x_c/w_c,y_c/w_c,z_c/w_c)\)。

第二步：有符号面积。 令 \(A=E(a,b,c)\)。 大三角形面积是 \(|A|/2\)。点 \(p\) 与三条边分别形成三个子三角形， 它们的面积比就是重心坐标：

\[\lambda_0=\frac{E(b,c,p)}{A},\qquad \lambda_1=\frac{E(c,a,p)}{A},\qquad \lambda_2=1-\lambda_0-\lambda_1.\]

第三步：覆盖判断。 对非退化三角形， 点在里面当且仅当三个 \(\lambda\) 都非负。屏幕像素的中心是 \((x+0.5,y+0.5)\)，所以遍历整数 \(x,y\) 后要加 0.5。

第四步：包围盒。 最小候选范围由顶点极值给出：

\[\begin{aligned} x_{\min}&=\max(0,\lfloor\min(x_a,x_b,x_c)\rfloor),& x_{\max}&=\min(W,\lceil\max(x_a,x_b,x_c)\rceil),\\ y_{\min}&=\max(0,\lfloor\min(y_a,y_b,y_c)\rfloor),& y_{\max}&=\min(H,\lceil\max(y_a,y_b,y_c)\rceil). \end{aligned}\]

若 \(|A|<\epsilon\)，三角形退化，直接跳过。否则除以极小面积会产生巨大坐标和 NaN， 后续属性插值与深度写入都会失去意义。

10.5 · 数值算例

一个像素中心的三个重心坐标

取屏幕三角形 \(a=(2,2)\)、\(b=(8,2)\)、\(c=(2,7)\)， 待测像素中心 \(p=(3.5,2.5)\)。边函数面积为：

\[A=E(a,b,c)=(8-2)(2-2)-(7-2)(8-2)=-30.\]

三个子面积比为：

\[\begin{aligned} \lambda_0&=\frac{E(b,c,p)}{-30}=0.65,\\ \lambda_1&=\frac{E(c,a,p)}{-30}=0.25,\\ \lambda_2&=1-0.65-0.25=0.10. \end{aligned}\]

三者都非负且和为 1，因此像素被覆盖。用它们重建 \(p\)： \(0.65a+0.25b+0.10c=(3.5,2.5)\)，与原始像素中心一致。

边界规则：当 \(\lambda\) 恰好为 0，点在三角形边上。 相邻三角形共享边时，需要统一采用 top-left 等规则，避免同一条边被重复光栅化。
10.6 · 伪代码与实现映射

最小三角形覆盖循环

JAVASCRIPT · 概念伪代码
const area = edge(a, b, c);
if (Math.abs(area) < 1e-12) return;

for (let y = minY; y < maxY; y += 1) {
  for (let x = minX; x < maxX; x += 1) {
    const p = { x: x + 0.5, y: y + 0.5 };
    const l0 = edge(b, c, p) / area;
    const l1 = edge(c, a, p) / area;
    const l2 = 1 - l0 - l1;
    const covered = Number.isFinite(l0) && l0 >= 0 && l1 >= 0 && l2 >= 0;
    if (covered) writePixel(x, y);
  }
}

RenderTorch 的 rasterize_triangle 使用 NumPy 批量计算整个包围盒， 并用 -1e-6 容差处理共享边。这个容差很实用，但不等同于严格的 top-left 规则。

10.7 · 自测

覆盖、裁剪与退化

问题 1：为什么不能先除以 w 再裁剪？

答案：相机背后或近平面外的点可能得到错误符号，且除法会破坏齐次空间中用于求交的线性关系。

问题 2：包围盒内的像素一定被三角形覆盖吗？

答案：不一定。包围盒只是候选范围，三个角上的像素常常在三角形外。

问题 3：面积接近零时为什么应直接跳过？

答案：面积比会放大数值误差，退化成线段或点的三角形没有稳定内部区域。

10.8 · 常见错误与调试

三角形消失、裂缝与重复边

  1. 整个三角形消失：检查裁剪平面的内外符号、\(w\) 的正负和视口 y 翻转。
  2. 三角形巨大：检查是否漏掉近裁剪，或把齐次坐标误当作 NDC。
  3. 边缘双缝：检查共享边是否被两个面同时写入，以及是否使用统一 top-left 规则。
  4. 像素偏移：检查是否使用像素中心 \(x+0.5,y+0.5\)，而不是整数角点。
  5. NaN 扩散：在面积比、逆深度和属性除法前检查退化与零分母。

最小复现应当只有 1 个三角形和 1 个像素。先打印 \(A\)、三个 \(\lambda\) 和像素中心，再逐步加入裁剪与深度。
