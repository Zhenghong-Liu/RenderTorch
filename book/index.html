项目全景

不是黑盒演示，而是一条可检查的因果链

RenderTorch 是一个模块化单体：Qt 只负责界面，Scene 保存状态，PyTorch 执行数值计算，软件渲染器生成 FrameBuffer。每种物理方法都有独立实现、可重复初始状态和自动化测试。

12 章阅读路线

先建立最小闭环，再替换求解方法

第 1–5 章建立共同语言；第 6–9 章深入布料；第 10–12 章连接刚体、软体、性能与后续扩展。每章都包含公式、伪代码、真实源码、图示、指标和调试清单。

01为什么从零搭建 3D 与物理教学项目先确定学习目标与边界，再决定需要自己实现什么。02总体架构与模块边界一个进程、清晰分层，让 UI、场景、计算与求解器各自保持简单。03最小闭环：相机、投影和 FrameBuffer把三维坐标经过视图、投影和视口变换送到像素平面。04软件光栅化与 Qt 图像显示裁剪三角形、判断像素覆盖、用深度测试决定谁可见。05物理模拟基础：粒子、时间步和积分用半隐式欧拉推进状态，用子步和累加器保持时间一致。06质点弹簧布料模型把布看作粒子网络，用结构、剪切和弯曲弹簧产生恢复力。07PBD：位置约束与迭代求解不直接求弹簧力，而是反复把粒子投影回距离约束允许的位置。08XPBD：柔度与拉格朗日乘子在 PBD 投影中加入 compliance，让“软硬”具备时间步一致的物理含义。09三种布料算法的比较在相同网格、固定条件和碰撞体下观察稳定性、误差与计算成本。10刚体与软体 Demo刚体保持形状，软体用距离和四面体体积约束抵抗变形。11性能、稳定性与局限性先测量，再优化；把 NaN、能量增长和约束误差当作诊断信号。12后续扩展方向沿现有边界扩展，而不是重写整个系统。
使用方式

把书与桌面程序放在一起读

先运行 python main_qt.py，在右侧面板切换模拟类型和布料算法。阅读第 6–9 章时保持相同初始状态，切换线框与实体视图，并把单步误差与书中指标对照。

第 9 章的浏览器交互示例可以暂停、重置并调整迭代与柔度。它用于展示趋势；精确算法行为以 GitHub 上的 Python 源码和测试为准。
