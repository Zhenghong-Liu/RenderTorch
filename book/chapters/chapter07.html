参数曲线：Bézier、B-spline 与 NURBS 概念

从参数区间和控制点出发，推导 Bézier 曲线并理解样条与权重的作用。

教材式推导可操作实验真实源码分层
学习目标

本章结束后你能够

  1. 用 de Casteljau 算法计算曲线点
  2. 解释控制点、基函数和参数连续性的意义

先验知识：基础多项式、第 2 章的向量加法与数乘。

控制点不都在曲线上

用加权平均画出一条平滑曲线

折线只由线段组成，而设计曲线需要一种可预测、可局部修改的平滑形状。 Bézier 曲线把控制点当作“引力”：参数 \(t\) 从 0 走到 1， 曲线在每个时刻取控制点附近的一个加权平均。除端点外，控制点通常并不落在曲线上。

控制点数量决定次数：两个控制点得到直线，三个得到二次曲线，四个得到三次曲线。 本章先掌握三次 Bézier 和 de Casteljau 算法，再把同一思想推广到 B-spline 与 NURBS。

图 7.1　虚线连接控制点形成控制多边形；绿色曲线是实际 Bézier 曲线。

符号与定义

次数、Bernstein 基与参数区间

设 \(n+1\) 个控制点为 \(\mathbf P_0,\ldots,\mathbf P_n\)。 次数为 \(n\) 的 Bézier 曲线定义为：

\[\mathbf B(t)=\sum_{i=0}^{n}B_i^n(t)\mathbf P_i,\qquad 0\le t\le1,\]

其中 Bernstein 基函数为：

\[B_i^n(t)=\binom{n}{i}t^i(1-t)^{n-i}.\]

基函数非负且总和为 1，所以曲线位于控制点的凸包内。 当 \(t=0\) 时只有 \(B_0^n=1\)，当 \(t=1\) 时只有 \(B_n^n=1\)， 因此曲线精确经过首尾控制点，但不保证经过中间控制点。

三次 Bézier 常写成工程中熟悉的形式：

\[\begin{aligned} \mathbf B(t)={}&(1-t)^3\mathbf P_0+3t(1-t)^2\mathbf P_1\\ &+3t^2(1-t)\mathbf P_2+t^3\mathbf P_3. \end{aligned}\]
逐步推导

de Casteljau：反复取相邻中点

直接展开 Bernstein 多项式可以计算曲线，但 de Casteljau 更容易手算，也更容易画出中间过程。 第一步在每对相邻控制点之间按比例 \(t\) 插值：

\[\mathbf Q_i=(1-t)\mathbf P_i+t\mathbf P_{i+1}.\]

对 \(\mathbf Q_i\) 重复同一操作，点数每轮减少 1；最后只剩一个点，就是 \(\mathbf B(t)\)。 对四个控制点，完整过程是：

\[\begin{aligned} \mathbf Q_0&=(1-t)\mathbf P_0+t\mathbf P_1,& \mathbf Q_1&=(1-t)\mathbf P_1+t\mathbf P_2,\\ \mathbf Q_2&=(1-t)\mathbf P_2+t\mathbf P_3,& \mathbf R_0&=(1-t)\mathbf Q_0+t\mathbf Q_1,\\ \mathbf R_1&=(1-t)\mathbf Q_1+t\mathbf Q_2,& \mathbf B(t)&=(1-t)\mathbf R_0+t\mathbf R_1. \end{aligned}\]

导数可以由控制多边形得到。一般地：

\[\frac{d\mathbf B}{dt} =n\sum_{i=0}^{n-1}B_i^{n-1}(t)(\mathbf P_{i+1}-\mathbf P_i).\]

因此切线方向来自控制点差分的加权和，线速度则包含参数区间的缩放。 若用曲线弧长重新参数化，才能得到近似匀速运动。

数值算例

四个控制点在 t = 0.5 的全部中间级

取二维控制点：

\[\mathbf P_0=(0,0),\quad \mathbf P_1=(1,2),\quad \mathbf P_2=(3,2),\quad \mathbf P_3=(4,0).\]

当 \(t=0.5\) 时，每一级都取相邻点的中点：

\[\begin{aligned} \mathbf Q_0&=(0.5,1),&\mathbf Q_1&=(2,2),&\mathbf Q_2&=(3.5,1),\\ \mathbf R_0&=(1.25,1.5),&\mathbf R_1&=(2.75,1.5),\\ \mathbf B(0.5)&=(2,1.5). \end{aligned}\]

导数使用二次 Bernstein 权重 \(0.25,0.5,0.25\)：

\[\mathbf B'(0.5)=3\left[0.25(1,2)+0.5(2,0)+0.25(1,-2)\right]=(4.5,0).\]

所以中点处的切线水平向右。实验会显示这 7 个点以及导数向量，便于逐项核对。

伪代码与实现映射

显式三级插值

JAVASCRIPT · 三次 de Casteljau
function bezierPoint(points, t) {
  const q = points.slice(0, -1).map((p, i) =>
    lerpPoint(p, points[i + 1], t));
  const r = [lerpPoint(q[0], q[1], t), lerpPoint(q[1], q[2], t)];
  return { point: lerpPoint(r[0], r[1], t), levels: [points, q, r] };
}

function lerpPoint(a, b, t) {
  return { x: a.x + (b.x - a.x) * t, y: a.y + (b.y - a.y) * t };
}

三次公式只是固定次数的特例。实际建模库通常实现任意次数，或直接提供 B-spline 求值器， 以便用更多控制点表达局部细节，而不必把次数提高到数值不稳定的程度。

自测

参数曲线不是按弧长等速前进

问题 1：二次 Bézier 在 t=0.5 时一定经过中间控制点吗？

答案：不一定。它等于 \(0.25\mathbf P_0+0.5\mathbf P_1+0.25\mathbf P_2\)，中间点权重只有 0.5。

问题 2：为什么曲线总在控制点凸包内？

答案：Bernstein 基函数非负且总和为 1，曲线是控制点的凸组合。

问题 3：把参数 t 从 0 到 1 线性推进，为什么看起来可能时快时慢？

答案：\(|\mathbf B'(t)|\) 随控制点布局改变，参数速度不等于弧长速度。

常见错误与调试

曲线形状与速度问题

  1. 端点接不上：检查曲线是否在 \(t=0\) 和 \(t=1\) 精确经过首尾控制点。
  2. 形状过冲：检查是否误用了高次多项式或错误节点向量；Bézier 本身位于凸包内。
  3. 动画忽快忽慢：区分参数时间与弧长时间，必要时建立弧长查找表。
  4. 导数方向错误：确认差分是 \(\mathbf P_{i+1}-\mathbf P_i\)，而不是反向。
  5. 拼接处有折角：检查相邻曲线端点的位置和切线是否按 \(C^0\)、\(C^1\) 或 \(C^2\) 要求匹配。
实现状态

曲线概念实验与样条扩展

浏览器概念实验 本章实验允许拖动四个控制点， 实时显示三次 Bézier 曲线、de Casteljau 每一级和导数。二维画布用于展示参数关系。

后续实现路线 RenderTorch 当前没有独立曲线或 NURBS 模块。 可以增加 B-spline 求值、节点向量校验和曲线采样为网格的函数；这些属于建模前端， 不应侵入光栅化核心。

从 Bézier 到 B-spline：B-spline 用局部支撑的基函数组合控制点： \(\mathbf S(u)=\sum_iN_{i,p}(u)\mathbf P_i\)。NURBS 再引入非负权重：

\[\mathbf R(u)= \frac{\sum_iN_{i,p}(u)w_i\mathbf P_i}{\sum_iN_{i,p}(u)w_i}.\]

均匀权重时 NURBS 退化为普通 B-spline；改变权重可以精确表示圆锥曲线等有理形状。 本章浏览器实验只实现 Bézier，不声称已实现完整 NURBS。
