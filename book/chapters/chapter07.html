Chapter 07 / 12

PBD：位置约束与迭代求解

不直接求弹簧力，而是反复把粒子投影回距离约束允许的位置。

阅读约 8 分钟3 个源码入口对应真实实现
01 · 直觉

先建立可观察的因果

PBD 把“粒子应该在哪里”当作主要问题。每条距离约束产生一个沿连线方向的修正，按逆质量分配给两个粒子，然后进入下一条约束。

求解采用顺序 Gauss–Seidel：修正立即生效，后面的约束看到更新后的位置。与之相对，同时计算所有修正再一次性累加，会在共享粒子多的高刚度网格中过度修正。

为什么稳定：位置投影不会像过硬的显式弹簧那样放大速度。但 PBD 的 stiffness 更像每轮投影比例，不是材料模量。
02 · 公式

用数学压缩核心关系

C = |xb − xa| − L0
Δxa = wa (C / (wa + wb)) n
Δxb = −wb (C / (wa + wb)) n

当前实现把修正乘以 stiffness。固定粒子权重为 0，因此不会被投影移动。

03 · 伪代码

把公式变成执行顺序

PSEUDOCODE
for iteration in range(iterations):
    for constraint in constraints:
        weight = inverse_mass[a] + inverse_mass[b]
        if weight == 0: continue
        delta = position[b] - position[a]
        correction = normalize(delta) * (length(delta) - rest_length)
        position[a] += stiffness * correction * inverse_mass[a] / weight
        position[b] -= stiffness * correction * inverse_mass[b] / weight

07 · 调试

常见问题与排查顺序

  1. 迭代增加但误差不降：检查约束是否按顺序求解，以及固定粒子权重。
  2. 网格爆炸：不要同时累加所有约束修正，改为逐条更新。
  3. 运动没有惯性：确认求解后根据位置变化重建速度。
