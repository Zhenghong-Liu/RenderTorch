2.2 · 位置与位移不是同一件事

用向量描述方向和大小

点回答“在哪里”，向量回答“向哪里、走多远”。 两个点相减得到位移向量；一个向量乘以标量会改变大小，但不改变方向所在的那条直线。 三维渲染中的相机视线、表面法线、光线方向和三角形边，都是向量。

本章采用右手坐标系：食指指向 +x，中指指向 +y，拇指指向 +z。 从 +x 转到 +y 时，右手定则给出的轴向是 +z。 换用左手系并不会让数学失效，但会改变叉积符号，因此整条管线必须保持同一约定。

2.3 · 符号与定义

三种最基本的向量运算

设 \(\mathbf a=(a_x,a_y,a_z)\)、\(\mathbf b=(b_x,b_y,b_z)\)。

点积：得到一个标量

\[\begin{aligned} \mathbf a\cdot\mathbf b &= a_xb_x+a_yb_y+a_zb_z, \\ \mathbf a\cdot\mathbf b &= \|\mathbf a\|\,\|\mathbf b\|\cos\theta. \end{aligned}\]

叉积：得到一个垂直于两个输入的方向

\[\mathbf a\times\mathbf b= \begin{pmatrix} a_yb_z-a_zb_y\\ a_zb_x-a_xb_z\\ a_xb_y-a_yb_x \end{pmatrix}.\]

归一化：保持方向，把长度变为 1

\[\hat{\mathbf a}=\frac{\mathbf a}{\|\mathbf a\|},\qquad \|\mathbf a\|=\sqrt{a_x^2+a_y^2+a_z^2}.\]

叉积不满足交换律：\(\mathbf a\times\mathbf b=-(\mathbf b\times\mathbf a)\)。 它的长度满足 \(\|\mathbf a\times\mathbf b\|=\|\mathbf a\|\,\|\mathbf b\|\sin\theta\)，恰好是以 a、b 为邻边的平行四边形面积。

零向量不能归一化。 当 \(\|\mathbf a\|=0\) 时，方向没有定义。 真实代码应在这一系统边界返回明确状态，而不是让 NaN 扩散到后续矩阵。
2.4 · 逐步推导

从点积得到夹角与投影

把向量 b 分解为“沿 a 的部分”和“垂直 a 的部分”。 沿 a 的单位方向是 \(\hat{\mathbf a}\)，投影标量为 \(\mathbf a\cdot\hat{\mathbf a}\)，投影向量为 \((\mathbf a\cdot\hat{\mathbf a})\hat{\mathbf a}\)。代入 \(\mathbf a\cdot\mathbf b=\|\mathbf a\|\|\mathbf b\|\cos\theta\)：

\[\begin{aligned} \operatorname{proj}_{\mathbf a}(\mathbf b) &=\frac{\mathbf a\cdot\mathbf b}{\|\mathbf a\|^2}\mathbf a, \\ \cos\theta &=\frac{\mathbf a\cdot\mathbf b}{\|\mathbf a\|\,\|\mathbf b\|}. \end{aligned}\]

因此，同向单位向量的点积为 1，反向为 −1，垂直为 0。 光照中的 \(\mathbf n\cdot\mathbf l\)、背面判断和视锥点乘，都建立在这一思想上。

叉积的垂直性可以直接验证。对任意向量 c：

\[(\mathbf a\times\mathbf b)\cdot\mathbf a=0,\qquad (\mathbf a\times\mathbf b)\cdot\mathbf b=0.\]

展开第一式会得到 \(a_yb_za_x-a_zb_ya_x+a_zb_xa_y-a_xb_za_y+a_xb_ya_z-a_yb_xa_z=0\)， 所有项两两抵消。由长度公式还可知，两个共线向量的叉积为零向量。

2.5 · 数值算例

同时计算点积、夹角和法线

取 \(\mathbf a=(1,2,3)\)、\(\mathbf b=(2,-1,2)\)。

\[\begin{aligned} \mathbf a\cdot\mathbf b &= 1\cdot2+2\cdot(-1)+3\cdot2=1, \\ \|\mathbf a\| &= \sqrt{14}\approx3.742, & \|\mathbf b\| &=3, \\ \cos\theta &= \frac{1}{3\sqrt{14}}\approx0.08909, & \theta&\approx84.89^\circ. \end{aligned}\]

叉积为：

\[\begin{aligned} \mathbf a\times\mathbf b &=(2\cdot2-3\cdot(-1),\;3\cdot2-1\cdot2,\;1\cdot(-1)-2\cdot2) \\ &=(7,4,-5). \end{aligned}\]

其长度为 \(\sqrt{90}\approx9.487\)。用 \(\sqrt{14}\cdot3\cdot\sin84.89^\circ\) 计算也得到相同结果。归一化后法线为 \((7,4,-5)/\sqrt{90}\approx(0.738,0.422,-0.527)\)。

符号检查： 交换 a、b 后，叉积应变为 (−7,−4,5)， 点积、长度和夹角不变。
2.6 · 伪代码与实现映射

渲染器需要反复使用的向量原语

PYTHON · 三维向量
def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def cross(a, b):
    return (
        a[1]*b[2] - a[2]*b[1],
        a[2]*b[0] - a[0]*b[2],
        a[0]*b[1] - a[1]*b[0],
    )

def normalize(a):
    length = dot(a, a) ** 0.5
    if length == 0:
        raise ValueError("zero vector has no direction")
    return tuple(component / length for component in a)

cos_theta = dot(a, b) / (dot(a, a)**0.5 * dot(b, b)**0.5)

GPU 着色器通常直接提供 dot、cross 和 normalize。 自己实现一次仍有价值：它能揭示数据类型、精度和零向量处理等问题。

2.7 · 自测

用符号性质检查结果

问题 1：(1,0,0) 与 (0,1,0) 的点积和叉积是什么？

答案：点积为 0；叉积为 (0,0,1)。

问题 2：为什么 (2,0,0) 与 (4,0,0) 的叉积为零？

答案：它们共线，sin θ=0，无法围成非零平行四边形。

问题 3：单位向量点积能否略大于 1？

答案：数学上不能；浮点舍入可能产生 1.0000001，计算夹角前应截断到 [−1,1]。

2.8 · 常见错误与调试

向量错误往往来自约定

  1. 检查手系：同一组坐标在左手系和右手系中，叉积方向相反。
  2. 检查分量顺序：叉积第二项常被误写成 \(a_zb_y-a_yb_z\)，导致整体符号错误。
  3. 区分点与方向：法线、光线用向量；表面位置用点。点与点不能直接点积。
  4. 检查长度：用归一化后的向量做方向判断，而不是任意长度的向量。
  5. 观察退化：三角形面积接近零时，法线会剧烈变化，应检查重复顶点或共线边。

固定测试向量 \(\mathbf x=(1,0,0)\)、\(\mathbf y=(0,1,0)\)、\(\mathbf z=(0,0,1)\)， 验证 \(\mathbf x\times\mathbf y=\mathbf z\)、\(\mathbf x\cdot\mathbf z=0\)，比随意画图更快定位符号问题。
