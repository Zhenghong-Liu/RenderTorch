XPBD：柔度与拉格朗日乘子

在 PBD 投影中加入 compliance，让“软硬”具备时间步一致的物理含义。

阅读约 8 分钟2 个源码入口对应真实实现
01 · 直觉

先建立可观察的因果

XPBD 为每条约束维护一个拉格朗日乘子 λ。它不仅看当前误差，也看这个子步中已经施加过多少修正，因此能表达有限的材料柔度。

compliance 越小，约束越硬。为了在不同子步下保持意义，代码使用 α̃ = α / h²。乘子在一个子步的所有迭代中保留，进入下一个子步时清零。

与 PBD 的关系：compliance 为 0 时，XPBD 的距离约束投影退化为 PBD 的硬约束形式。
02 · 公式

用数学压缩核心关系

α̃ = α / h²
Δλ = (−C − α̃λ) / (wa + wb + α̃)
Δxa = −wa Δλ n
Δxb = wb Δλ n

这里的 h 是子步长，而不是一次渲染帧的时间。

03 · 伪代码

把公式变成执行顺序

PSEUDOCODE
effective_compliance = compliance / (step * step)
lambdas.zero_()
for iteration in range(iterations):
    for constraint in constraints:
        error = distance - rest_length
        delta_lambda = (-error - alpha * lambdas[i]) / (weight + alpha)
        lambdas[i] += delta_lambda
        position[a] -= inverse_mass[a] * delta_lambda * normal
        position[b] += inverse_mass[b] * delta_lambda * normal

07 · 调试

常见问题与排查顺序

  1. 改子步后软硬变化：检查是否使用 α / h²。
  2. 约束越来越硬或振荡：确认 λ 没有在每次迭代前被清零。
  3. 仍无法收敛：减小 compliance 或增加迭代，先分别观察。
