15.2 · 从像素发出光线

用求交代替三角形覆盖

光栅化从物体出发，把三角形投影到屏幕；光线追踪从像素出发，沿视线反向发射光线， 询问它首先碰到哪个物体。命中后可以计算法线、光照、反射、折射与阴影。

两种方法得到的是同一个成像问题：从相机穿过像素的射线，与场景相互作用后到达相机。 光栅化用硬件友好的三角形流程解决它，光线追踪用通用求交提供更直接的全局效果表达。

图 15.1　一条主射线命中球面，法线决定后续反射或折射方向。

15.3 · 符号与定义

射线、球心与命中参数

射线定义为 \(\mathbf p(t)=\mathbf o+t\mathbf d\)，其中 \(\mathbf o\) 是原点，\(\mathbf d\) 是方向，\(t\ge0\) 是沿射线的距离参数。 方向归一化时，\(t\) 也可直接解释为世界距离。

球由球心 \(\mathbf c\) 与半径 \(r\) 定义。命中的要求是： \(t\) 为实数、\(t\ge0\)，并且在所有候选物体中取最小值。

若射线起点位于物体内部，二次方程可能给出一个负根和一个正根。 只接受正根；若需要透明物体出口，可把负根转换为沿反方向的出口距离。

15.4 · 逐步推导

ray-sphere 二次方程与反射

第一步：代入射线。 球面方程为 \(\lVert\mathbf p-\mathbf c\rVert^2=r^2\)。代入 p(t) = o + t d：

\[\lVert\mathbf o+t\mathbf d-\mathbf c\rVert^2=r^2.\]

令 \(\mathbf m=\mathbf o-\mathbf c\)，展开得到：

\[(\mathbf d\cdot\mathbf d)t^2+ 2(\mathbf m\cdot\mathbf d)t+(\mathbf m\cdot\mathbf m-r^2)=0.\]

即 \(at^2+bt+c=0\)，其中 \(a=\mathbf d\cdot\mathbf d\)、 \(b=2\mathbf m\cdot\mathbf d\)、\(c=\mathbf m\cdot\mathbf m-r^2\)。

第二步：判别式与根。

\[\Delta=b^2-4ac,\qquad t_{\pm}=\frac{-b\pm\sqrt{\Delta}}{2a}.\]

若 \(\Delta<0\)，没有交点；否则检查两个根，保留有效的最小非负 \(t\)。 当 \(a\) 接近零时，射线退化，应跳过而不是除以零。

第三步：命中点与法线。

\[\mathbf p=\mathbf o+t\mathbf d,\qquad \mathbf n=\operatorname{normalize}(\mathbf p-\mathbf c).\]

第四步：镜面反射。 将方向沿法线分解，反向法线分量：

\[\mathbf r=\mathbf d-2(\mathbf d\cdot\mathbf n)\mathbf n.\]

代码中对应 r = d − 2(d · n)n。反射方向应单位化， 并以微小偏移从表面发出，避免自交。

第五步：概念扩展。 折射使用 Snell 定律。设入射方向指向表面， 法线朝向入射侧，\(\eta=n_1/n_2\)、\(\cos i=-\mathbf N\cdot\mathbf I\)：

\[\mathbf T=\eta\mathbf I+ \left(\eta\cos i-\sqrt{1-\eta^2(1-\cos^2i)}\right)\mathbf N.\]

根号内为负时发生全内反射。Fresnel 可用 Schlick 近似 \(F=F_0+(1-F_0)(1-\cos\theta)^5\)。 路径追踪进一步用渲染方程递归积分多条随机路径；本章浏览器实验不实现完整 PBR 或路径追踪。

15.5 · 数值算例

一个球的两个交点

取 \(\mathbf o=(0,0,-5)\)、\(\mathbf d=(0,0,1)\)， 球心 \(\mathbf c=(0,0,0)\)、半径 \(r=2\)。

\[a=1,\qquad b=2(-5)=-10,\qquad c=25-4=21,\qquad \Delta=100-84=16.\]
\[t_{\pm}=\frac{10\pm4}{2}=3,\ 7.\]

最近交点为 \(t=3\)，位置 \(\mathbf p=(0,0,-2)\)，法线 \(\mathbf n=(0,0,-1)\)。 因为 \(\mathbf d\cdot\mathbf n=-1\)，反射方向为：

\[\mathbf r=(0,0,1)-2(-1)(0,0,-1)=(0,0,-1).\]

增大最大反射次数后， secondary ray 会继续寻找其他球或平面，形成可见的反射贡献。

15.6 · 伪代码与实现映射

最近命中和受限反射

JAVASCRIPT · 概念伪代码
const oc = subtract(origin, center);
const a = dot(direction, direction);
const b = 2 * dot(oc, direction);
const c = dot(oc, oc) - radius * radius;
const discriminant = b * b - 4 * a * c;
let nearest = Infinity;
if (a > 1e-12 && discriminant >= 0) {
  for (const sign of [-1, 1]) {
    const t = (-b + sign * Math.sqrt(discriminant)) / (2 * a);
    if (t >= 0 && t < nearest) nearest = t;
  }
}
if (nearest !== Infinity) {
  const p = add(origin, scale(direction, nearest));
  const n = normalize(subtract(p, center));
  const r = subtract(direction, scale(n, 2 * dot(direction, n)));
}

RenderTorch 当前没有光线追踪器。本章实验是独立浏览器概念实现， 通过球与平面的求交展示射线模型，不替代现有光栅管线。

15.7 · 自测

求交、反射与算法边界

问题 1：为什么两个根中要取最小非负值？

答案：射线首先遇到的是沿方向最近的表面；负根位于射线反方向。

问题 2：判别式为负表示什么？

答案：射线不与球面相交。

问题 3：反射公式中为什么要减 2(d·n)n？

答案：它把方向沿法线的分量反向，同时保留切向分量。

问题 4：最大反射次数为 0 时会看到什么？

答案：只计算主射线命中的直接颜色，不继续追踪 secondary ray。

15.8 · 常见错误与调试

漏交、自交与反射噪声

  1. 球体出现空洞：检查方向是否归一化、判别式符号与根的有效性。
  2. 表面出现黑点： secondary ray 起点与表面重合导致自交，应沿新方向做微小偏移。
  3. 法线方向错误：球面法线由命中点减球心得到；若起点在内部，需按入射侧决定朝向。
  4. 反射越来越暗：每次反弹可按材质能量衰减，但不能在线性颜色中提前 clamp。
  5. 多样本边缘闪烁：使用固定、可复现的样本偏移，并避免无约束随机数造成测试不可重复。

先用 1 条光线、0 次反射验证球体与平面，再增加多样本，最后开启 secondary ray。

15.9 · 实现状态

光栅与光线追踪的定位

浏览器概念实验 本章实现 CPU ray-sphere、平面求交、镜面反射， 最大反射次数 0–3，每像素 1–4 条光线，只在用户操作后重绘。

现有 RenderTorch renderer/pipeline.py 走裁剪、透视除法、三角形光栅和 z-buffer；没有 BVH、光线求交、反射、折射或路径追踪。

后续实现路线 先添加射线与球/三角形求交， 再增加简单 BVH 和阴影射线；材质完整后再加入 Fresnel、折射、HDR 与随机路径积分。
