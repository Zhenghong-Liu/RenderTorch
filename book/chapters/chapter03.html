Chapter 03 / 12

最小闭环：相机、投影和 FrameBuffer

把三维坐标经过视图、投影和视口变换送到像素平面。

阅读约 8 分钟3 个源码入口对应真实实现
01 · 直觉

先建立可观察的因果

轨道相机围绕目标点旋转。视图矩阵把世界坐标变成相机坐标，透视矩阵把视锥映射到齐次裁剪空间，视口矩阵再把 NDC 映射到屏幕像素。

项目使用行向量约定：world × View × Projection × Viewport。这与不少 OpenGL 教材的列向量顺序不同，混用会导致看似随机的旋转和裁剪错误。

生活类比：相机位置决定你站在哪里，视锥决定你能看多宽，FrameBuffer 则相当于一张等待曝光的数字底片。
02 · 公式

用数学压缩核心关系

pclip = pworld Mview Mprojection
pndc = pclip / wclip
xscreen = (xndc + 1) width / 2
yscreen = (1 − yndc) height / 2

透视除法必须在近裁剪面之后进行。像素 Y 向下，而 NDC Y 向上，所以需要翻转。

03 · 伪代码

把公式变成执行顺序

PSEUDOCODE
view = look_at(camera.position, camera.target, world_up)
projection = perspective(fov_y, aspect, near, far)
clip = world_vertices @ view @ projection
inside = clip.z >= -clip.w and clip.z <= clip.w
ndc = inside_clip / inside_clip.w
pixel = viewport(ndc, width, height)

07 · 调试

常见问题与排查顺序

  1. 所有面都消失：检查 forward 方向与近远平面符号。
  2. 图像上下颠倒：检查视口矩阵是否翻转 Y。
  3. 窗口缩放后物体被拉长：确认 projection_aspect 使用最新宽高比。
