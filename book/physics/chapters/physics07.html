7.2 · 先划清边界

PBD 刚度：一次投影修正多少差距

第五章的 PBD 用位置投影直接减少约束误差。为了避免和 XPBD 的柔度符号混淆，本章把 PBD 的投影刚度记作 \(s\in[0,1]\)。对距离约束 \(C=L-L_0\)，单位方向为 \(\mathbf n=(\mathbf p_b-\mathbf p_a)/L\)，一次修正向量是

\[ \Delta\mathbf p_{\mathrm{corr}} =s\frac{C}{w_a+w_b}\mathbf n, \qquad \mathbf p_a'\leftarrow\mathbf p_a+w_a\Delta\mathbf p_{\mathrm{corr}}, \qquad \mathbf p_b'\leftarrow\mathbf p_b-w_b\Delta\mathbf p_{\mathrm{corr}}. \]

\(s=1\) 表示尽力在一次投影中满足这条约束；\(s<1\) 只修正一部分。\(s\) 是无量纲的投影比例，不是“弹簧有多硬”的材料参数，也没有自动补偿时间步变化。

为什么不继续叫它柔度。同一个 \(s=0.5\) 在大小步长下都只修正当前差距的一半，但 XPBD 的正柔度会通过 \(h^2\) 改变实际响应。把两者混成一个旋钮，会误以为已经表达了材料与时间步的关系。

本节 Demo 的公平约定。xpbd-compliance 的 PBD 一侧始终调用 projectDistance(a,b,L0,1)，即 \(s=1\)。不会为了迁就非零柔度而偷偷降低 PBD 刚度；只有 XPBD 一侧读取柔度控件。两侧从独立复制的相同拉伸状态出发。

本节小结：PBD 刚度控制单次修正比例，XPBD 柔度描述约束对变形的抵抗，二者不能互换。

7.3 · 软硬的物理直觉

约束势能：偏差越大，储能越多

弹簧的势能让我们直观看到“拉得越远，越想恢复”。对一条距离约束，可以用二次势能作为 PBD 软硬的教学直觉：

\[ U(C)=\frac12 kC^2, \qquad \mathbf F_C=-\frac{\partial U}{\partial\mathbf p}. \]

当 \(C>0\) 时，势能随拉伸增大；当 \(C<0\) 时，势能随压缩增大。\(k\) 越大，同样偏差对应的势能越大，也越难拉伸。\(C=0\) 时势能最低。

势能直觉不等于 PBD 真的施加了弹簧力。PBD 在预测位置后直接投影，并不计算上式中的力再积分。真实材料还可能有非线性、阻尼、塑性或断裂，单一二次函数不能代表全部行为。

柔度与势能参数要分清。XPBD 使用柔度 \(\alpha\) 进入离散约束方程；不能不加推导就把本章的 \(\alpha\) 当成上式 \(k\) 的倒数。约束函数、单位、离散格式与逆质量都会影响对应关系。这里的势能只解释“为什么偏差应当受到抵抗”，不是精确能量账本。

诊断仍要看几何。势能是否为非负有限值，不能代替距离误差检查。本章读数直接报告约束长度、相对误差与乘子，避免用虚构的能量掩盖投影没有收敛。

本节小结：二次势能提供软硬直觉，但 PBD 的位置修正与 XPBD 的柔度参数仍须按各自公式理解。

7.4 · 材料参数

柔度：越大越容易产生约束偏差

XPBD（Extended Position Based Dynamics，扩展位置约束动力学）用柔度 \(\alpha\ge0\) 表示约束对位置偏差的抵抗程度。\(\alpha=0\) 表示理想刚硬约束；\(\alpha>0\) 表示允许一定偏差的较软约束。对其他条件相同的情形，柔度越大，投影后留下的偏差通常越大。

柔度的单位取决于约束函数的定义。若 \(C\) 是长度，约束势能写成 \(\frac12\alpha^{-1}C^2\) 时，\(\alpha\) 可理解为该二次项的逆刚度；但本章的离散求解公式才是 Demo 实际执行的依据。

\[ \alpha=0\quad\Longleftrightarrow\quad\text{理想刚硬约束}, \qquad \alpha>0\quad\Longleftrightarrow\quad\text{允许约束偏差}. \]

它不等同于 PBD 的 \(s\)。\(s\) 限定在 \([0,1]\)，直接缩放一次位置修正；\(\alpha\) 进入乘子方程，还与子步长度 \(h\) 组合成有效柔度。把 \(s\) 调小可能只是每轮少修一点，把 \(\alpha\) 调大则改变了离散系统的材料响应。

本 Demo 的零柔度校验。当 \(\alpha=0\) 时，距离 XPBD 的增量公式退化为 PBD 的全刚度投影。两侧独立状态应通过真实共享核心得到相同位置与相同误差。这是接口等价检查，不是把 PBD 重新调参凑出来的结果。

本节小结：柔度是 XPBD 的材料参数；零柔度给出硬约束，正柔度允许偏差，且不能直接当作 PBD 刚度。

PBD 与 XPBD 的距离柔度对照

浏览器概念实验；默认暂停。两侧从独立复制的相同拉伸状态出发，PBD 始终全刚度。调节柔度、子步与迭代，比较真实投影后的有效柔度、lambda、最终长度和最大相对距离误差。

7.5 · 时间步补偿

有效柔度：把材料参数换算到当前子步

实际投影使用子步长 \(h\)，不是共享界面固定的 \(1/60\,\mathrm s\)。XPBD 在每个子步内使用有效柔度

\[ \tilde{\alpha}=\frac{\alpha}{h^2}. \]

\(\alpha\) 是控件中的材料柔度，\(\tilde{\alpha}\) 是代入乘子方程的有效柔度。\(h\) 越小，\(h^2\) 越小，因此同样的 \(\alpha\) 会得到越大的 \(\tilde{\alpha}\)。这正是在补偿更短子步带来的离散尺度变化。

规定算例。取 \(\alpha=0.01\)、\(h=1/60\,\mathrm s\)，则

\[ \tilde{\alpha}=\frac{0.01}{(1/60)^2} =0.01\times60^2 =36. \]

所以题目要求的精确关系是 alpha=0.01, h=1/60 → alpha_tilde=36。若改为两个子步，\(h=1/120\,\mathrm s\)，则 \(\tilde{\alpha}=144\)；若四个子步，\(h=1/240\,\mathrm s\)，则 \(\tilde{\alpha}=576\)。这些数不是标签：Demo 会把它们传入真实投影并改变最终长度。

运输时间与物理子步。共享 UI 每次更新固定运输 \(1/60\,\mathrm s\)。若选择 \(s\) 个内子步，则每个实际子步为

\[ h=\frac{1}{60s}\,\mathrm s, \qquad s h=\frac1{60}\,\mathrm s. \]

因此改变子步数不会偷偷改变一次更新推进的模拟时间，但会改变真实调用中的 \(h\)、\(\tilde{\alpha}\)、乘子重置次数与投影结果。

本节小结：先算 \(\tilde{\alpha}=\alpha/h^2\)，再迭代；控件柔度与实际子步长共同决定求解。

7.6 · 约束的反作用

乘子：记录约束为消除偏差所做的修正

投影不仅要移动位置，还要记录“这个约束当前贡献了多大修正”。XPBD 用拉格朗日乘子 \(\lambda\) 表示这份累积量。对一条距离约束，设 \(\mathbf n\) 为两端连线单位方向，则梯度为

\[ \nabla_a C=-\mathbf n, \qquad \nabla_b C=\mathbf n. \]

每轮先算增量 \(\Delta\lambda\)，再更新累积乘子 \(\lambda'\leftarrow\lambda+\Delta\lambda\)。修正方向与增量相乘后，才会按逆质量分配到各质点。乘子不是直接施加给质点的力，也不是跨帧保留的弹簧冲量；它是当前子步这条约束的状态。

符号只是约定，但必须一致。本章遵循共享核心的符号：拉伸时 \(C>0\)，从 \(\lambda=0\) 开始的 \(\Delta\lambda\) 为负，位置修正把两端拉近。若自己写公式时把 \(\Delta\mathbf p\) 的符号写反，却仍使用核心的乘子历史，结果就会来回振荡。

每个约束一份。多条约束不能共用一个 \(\lambda\)。当前 Python physics/cloth/xpbd.py 为每条距离约束保存一个乘子；physics/softbody/xpbd.py 还为每个四面体体积约束单独保存 volume_lambdas。本章距离 Demo 只有一条约束，因此只需一个当前 \(\lambda\)。

读数含义。“当前 lambda”是最后一个实际子步、最后一次迭代后的累积值；“最大乘子绝对值”用于观察面积约束在本步内出现过的最强修正。两者都不是跨子步累加的历史总和。

本节小结：乘子记录约束修正，增量更新改变乘子，每个约束必须独立保存。

7.7 · 核心方程

增量更新：同时考虑当前误差与旧乘子

对距离约束，记 \(W=w_a+w_b\)。XPBD 不是每轮把 \(\lambda\) 清零，而是从上一轮的同子步乘子出发，计算

\[ \Delta\lambda =\frac{-C-\tilde{\alpha}\lambda}{W+\tilde{\alpha}}, \qquad \lambda'\leftarrow\lambda+\Delta\lambda. \]

第一项 \(-C\) 要求减少当前约束偏差；第二项 \(-\tilde{\alpha}\lambda\) 约束同一子步内乘子不要无限累积。得到增量后，位置更新为

\[ \mathbf p_a'\leftarrow\mathbf p_a-w_a\Delta\lambda\,\mathbf n, \qquad \mathbf p_b'\leftarrow\mathbf p_b+w_b\Delta\lambda\,\mathbf n. \]

这个顺序对应共享接口 projectDistanceXPBD(a,b,restLength,compliance,dt,lambda)：它返回新的 {a,b,lambda}，调用者必须写回位置，并把返回的 lambda 传给下一次同子步迭代。

完整算例。取 \(\mathbf p_a=(0,0)\)、\(\mathbf p_b=(3,0)\)、\(L_0=2\)、\(w_a=w_b=1\)、\(\alpha=0.01\)、\(h=1/60\,\mathrm s\)、\(\lambda=0\)。有 \(C=1\)、\(\mathbf n=(1,0)\)、\(W=2\)、\(\tilde{\alpha}=36\)，所以

\[ \Delta\lambda=\frac{-1-36\times0}{2+36}=-\frac1{38}, \qquad \lambda'=-\frac1{38}, \] \[ \mathbf p_a'=\left(\frac1{38},0\right), \qquad \mathbf p_b'=\left(3-\frac1{38},0\right), \qquad L'=3-\frac2{38}=\frac{56}{19}\approx2.947368421. \]

相对误差为 \(|L'-2|/2=1/19\approx0.052631579\)。这正是共享核心一次真实投影的结果；它说明正柔度不会让第一次投影像 \(\alpha=0\) 那样精确满足距离。

本节小结：先算增量，再累加乘子，最后按梯度与逆质量移动位置。

7.8 · 状态管理

lambda 生命周期：子步清零，迭代继承

\(\lambda\) 的生命周期比“一帧”更短。对每条约束，正确顺序是：每个实际子步开始置零；同一子步的所有迭代继承并写回；下一个子步再次置零。

\[ \lambda_j^{(s,0)}=0, \qquad \lambda_j^{(s,k+1)} =\lambda_j^{(s,k)}+\Delta\lambda_j^{(s,k)}, \qquad \lambda_j^{(s+1,0)}=0. \]

这里 \(s\) 是子步编号，\(k\) 是该子步内的迭代编号。上式说明乘子只在同一子步的迭代间累积，不能把上一子步的 \(\lambda\) 带入下一子步。

最小伪代码。

for each inner substep:
    h = (1/60) / substeps
    lambda = 0                       # 每条约束各自清零
    repeat iterations times:
        result = projectDistanceXPBD(a, b, L0, alpha, h, lambda)
        a, b = result.a, result.b
        lambda = result.lambda        # 同子步下一次迭代必须继承
measure final length and lambda

重建与重置。改变柔度、子步数或迭代数会重建相同初始状态，因此 \(\lambda\) 必须回到零。点击重置也回到零。面积 Demo 在用户拖动顶点后同样清零，避免旧几何的乘子被应用到用户刚替换的位置。

零时间步是核心接口的边界。共享距离与面积 XPBD 在 \(\Delta t=0\) 时返回克隆并保留传入的 \(\lambda\)。本章 Demo 的有效时间步始终为正，不把“接口保留”误写成“求解器应跨子步保留”。

非有限状态。若几何、时间步、乘子或位置出现非有限值，Demo 暂停并要求重置，不通过裁剪数值制造一个看似有限的lambda。

本节小结：lambda 是每条约束、每个子步的临时累积状态；清零与继承缺一不可。

7.9 · 距离求解

距离 XPBD：从几何梯度到软硬响应

把约束误差在当前预测位置附近线性化，可以写成 \(C+\nabla C\cdot\Delta\mathbf p\approx0\)。距离约束的两个梯度大小都是 1，因此加权梯度平方和为

\[ W=\sum_i w_i\lVert\nabla_i C\rVert^2=w_a+w_b. \]

结合有效柔度，就得到上一节的增量公式。\(\alpha=0\) 时，它变为 \(\Delta\lambda=-C/W\)，位置修正恰好是 PBD 的 \(s=1\) 投影；\(\alpha>0\) 时，分母多出 \(\tilde{\alpha}\)，第一次修正通常较小。

为什么要迭代。一条独立距离约束在零柔度下投影一次即可满足，但正柔度仍需继续逼近约束方程。多个约束共用质点时，后一条约束还会改变前一条的长度，因此要重复从最新位置计算 \(C\)、\(\mathbf n\) 与 \(\Delta\lambda\)。

误差指标。本章使用最大相对距离误差

\[ E=\max_j\frac{|L_j-L_{0,j}|}{L_{0,j}}. \]

距离 Demo 只有一条约束，因此它就是该约束的相对误差；两侧并列时再取两种方法的较大值作为总览。\(L_0=0\) 时这个比值没有定义，实现必须拒绝，不能输出一个假零误差。

退化与固定端。两点重合时单位方向没有定义；两端都固定时 \(W=0\)。共享核心在两点重合或两端权重之和为零时返回未改变的新对象；距离 Demo 只检查非负权重与两点不重合，当前控件不会创建两个固定端点，因此不会因双固定端而暂停。

本节小结：距离 XPBD 用同一梯度框架统一硬约束与软约束，并以真实迭代后的相对误差检查结果。

7.10 · 从面积到体积

体积梯度：二维四粒子面积类比

area-constraint 是二维四粒子面积类比，不是三维体积求解器。它用四边形顶点 \(\mathbf p_0,\mathbf p_1,\mathbf p_2,\mathbf p_3\) 的有向面积约束面积，从而帮助理解体积约束使用的梯度方法。

按原始顶点顺序计算鞋带公式：

\[ A=\frac12\sum_{i=0}^{3} \left(x_i y_{i+1}-x_{i+1}y_i\right), \qquad \mathbf p_4=\mathbf p_0. \]

令 \(\sigma\) 为当前输入多边形的原始环绕方向符号，静止面积为 \(A_0>0\)，则约束误差为 \(C=A-\sigma A_0\)。这样顺时针与逆时针不会因为一个随意硬编码的正号而被误判。共享 projectAreaXPBD 在每次调用中按传入顶点的当前有向面积确定 \(\sigma\)，Demo 会拒绝翻面或退化拖拽。

四个顶点的面积梯度为

\[ \begin{aligned} \mathbf g_0&=\left(\frac{y_1-y_3}{2},\frac{x_3-x_1}{2}\right),& \mathbf g_1&=\left(\frac{y_2-y_0}{2},\frac{x_0-x_2}{2}\right),\\ \mathbf g_2&=\left(\frac{y_3-y_1}{2},\frac{x_1-x_3}{2}\right),& \mathbf g_3&=\left(\frac{y_0-y_2}{2},\frac{x_2-x_0}{2}\right). \end{aligned} \]

定义加权梯度平方和 \(W=\sum_i w_i\lVert\mathbf g_i\rVert^2\)，增量更新与距离约束同形：

\[ \Delta\lambda=\frac{-C-\tilde{\alpha}\lambda}{W+\tilde{\alpha}}, \qquad \lambda'\leftarrow\lambda+\Delta\lambda, \qquad \mathbf p_i'\leftarrow\mathbf p_i+w_i\Delta\lambda\,\mathbf g_i. \]

真实接口 projectAreaXPBD(p0,p1,p2,p3,restArea,compliance,dt,lambda) 返回 {particles,lambda}。Demo 从面积为 \(3\)、静止面积为 \(2\) 的非退化矩形出发，逐次调用它，并保留返回的 lambda 历史。拖拽会暂停、把坐标限制在有限交互区域、检查环绕方向与非零面积，再清零乘子。

三维扩展。把四点换成四面体四个顶点，定义有向体积

\[ V=\frac16(\mathbf p_b-\mathbf p_a)\cdot \left[(\mathbf p_c-\mathbf p_a)\times(\mathbf p_d-\mathbf p_a)\right]. \]

对每个顶点求 \(\nabla_i V\)，仍可用 \(W=\sum_iw_i\lVert\nabla_iV\rVert^2\) 构造相同的增量形式。体积是面积的三维推广，但单位、梯度与退化条件都不同，不能把二维面积 API 当作现有 Python 软体的体积实现。

当前实现边界。Python physics/softbody/xpbd.py 已有四面体体积约束；当前 Python 软体没有面积约束。本章面积 Demo 只是浏览器概念实验。重合、共线或非有限面积没有可靠梯度，Demo 会暂停并提示重置。

本节小结：面积与体积都通过约束梯度驱动增量投影；二维面积实验用于解释方法，不冒充现有三维能力。

二维四粒子面积约束与拖拽

浏览器概念实验；默认暂停。调用真实 projectAreaXPBD，从可复现四边形出发，调节柔度与迭代并拖拽顶点。当前 Python 软体没有面积约束；本实验只用于理解体积梯度。

7.11 · 时间步与结果

子步不变性：近似保持，而非逐位相等

理想情况下，固定材料柔度 \(\alpha\) 后，把同一段物理时间拆成更多子步，求解结果应大致保持接近。这是因为有效柔度按 \(\tilde{\alpha}=\alpha/h^2\) 随子步长变化，而不是让材料参数随着 UI 帧率随意漂移。

本章距离 Demo 每次共享 UI 更新执行 \(s\) 个真实内子步，每个子步长 \(h=1/(60s)\)，总模拟时间始终增加 \(1/60\,\mathrm s\)。因此比较不同 \(s\) 时，应比较相同模拟时间后的长度与误差，而不是只比较调用次数。

为什么只是近似。实际位置投影是非线性的：每轮方向 \(\mathbf n\) 与梯度都会随位置改变；有限迭代次数、Gauss–Seidel 顺序、外力积分和约束耦合也会影响数值路径。更多子步通常让结果更接近连续极限，但不保证任意迭代数下误差单调，也不保证逐位相同。

\[ \text{相同 }\alpha,\ \text{相同模拟时间}, \qquad h\downarrow\ \Longrightarrow\ \text{结果通常更接近}, \]

这里的箭头是近似趋势，不是严格定理。零柔度的一条独立距离约束可能很快得到相同几何解；正柔度、多条约束或面积梯度的一轮结果则可能保留可见差异。

怎样做公平实验。固定初始状态、约束、材料柔度与总模拟时间，只改子步数；同时观察有效柔度、最终约束误差与乘子。若发现“改子步只改标签”，应检查真实投影是否仍收到旧的 \(h\)，以及模拟时间是否被错误地乘上子步数。

本节小结：子步不变性依赖有效柔度补偿与正确求解，但非线性有限迭代只能给出近似一致。

7.12 · 可检查的实现

伪代码与调试：让状态、时间和梯度都可复现

距离对照伪代码。两侧必须独立复制，PBD 始终使用全刚度；每个子步只重置 XPBD 的 lambda：

initial = stretchedDistanceState()
pbd = clone(initial)
xpbd = clone(initial)
for each UI update:                         # 模拟时间增加 1/60 s
    for each inner substep:
        h = (1/60) / substeps
        xpbd.lambda = 0
        repeat iterations times:
            pair = RTPhysics.projectDistance(pbd.a, pbd.b, L0, 1)
            pbd.a, pbd.b = pair.a, pair.b
            soft = RTPhysics.projectDistanceXPBD(
                xpbd.a, xpbd.b, L0, compliance, h, xpbd.lambda)
            xpbd.a, xpbd.b, xpbd.lambda = soft.a, soft.b, soft.lambda
measure both lengths, errors and xpbd.lambda
time += 1/60

当前 Python 实现。physics/cloth/pbd.py 有结构、剪切、弯曲三类距离约束；physics/cloth/xpbd.py 为这些距离约束保存柔度与 lambda，并在每次子步求解开始时清零。physics/common/simulation.py 默认 fixed_dt=1/120、substeps=2，所以实际子步为 \(h=1/240\,\mathrm s\)。

physics/softbody/geometry.py 生成结构/剪切距离约束、表面三角形和固定六个四面体；physics/softbody/xpbd.py 求解这些距离约束与四面体体积约束。当前 Python 软体没有面积约束，没有独立弯曲约束（布片的 bend 仍是距离约束，不是独立弯曲能量或二面角约束），没有自碰撞，也没有中心粒子参与体积。增加立方体分辨率会增加距离网格与表面三角形，但体积分解仍固定为六个四面体，不能据此声称已有精细体积网格。

浏览器边界。两个 Demo 使用 JavaScript 双精度与共享 UI/核心，是有界教学实验，不是生产求解器。Python 使用 float32 张量；数值精度、约束集合与积分路径不同，因此本章只比较概念与趋势，不承诺两种实现逐位一致。

本章小结：XPBD 用柔度表达软硬，用有效柔度匹配子步，用乘子增量处理约束，并用生命周期、几何检查与真实读数保证结果可复现。
