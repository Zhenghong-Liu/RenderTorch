8.1 · 学习目标

本章结束后你能够

  1. 设计只改变求解方法的公平比较，辨认共同量与各自参数
  2. 追踪一次更新中的力积分、位置预测、投影与速度重建
  3. 读取最终长度、最大相对距离误差、实际动能与独立势能账本
  4. 用所选子步和固定参考子步检查相同总时间下的近似一致性
  5. 依据误差、能耗、成本与模型限制选择方法，而非寻找通用赢家

先验知识：第四章的胡克定律与稳定步长、第五章的 PBD 距离投影与速度重建、第七章的 XPBD 柔度与 lambda 生命周期、动能和弹性势能。

8.2 · 比较之前

公平比较：先固定题目，再更换解法

共同初始条件是公平比较的第一项。“哪个算法更好”只有在题目、初值和评分方式相同时才可回答。本章把三种方法都用于一条两粒子弹簧：两端质量相同，初始位置关于原点对称，初始速度方向相反，因此弹簧先被拉长。三条运行拥有独立复制的初始状态，不会共享位置或乘子。

共同题目是：质点质量 \(m\) 相同，目标长度 \(L_0\) 可调，初始长度为 \(1.5L_0\)，初始速度大小为 \(0.6\,\mathrm{m/s}\)。质量弹簧的劲度系数固定为 \(k=120\,\mathrm{N/m}\)，XPBD 的柔度固定为 \(\alpha=0.01\,\mathrm{s^2/kg}\)；这两个数分别属于不同模型，不是为了数值相等而互相换算。

\[ \mathbf p_a(0)=(-0.75L_0,0),\quad \mathbf p_b(0)=(0.75L_0,0),\quad \mathbf v_a(0)=(-0.6,0),\quad \mathbf v_b(0)=(0.6,0). \]

只改变求解路径。共享界面每次更新运输 \(H=1/60\,\mathrm s\)。质量弹簧读取 \(m,L_0\)，用显式力积分；PBD 与 XPBD 读取相同的 \(m,L_0\)，但迭代旋钮只改变它们的投影轮数。不能把“迭代八次”理解成质量弹簧也积分八次。

先问是否可比。如果一侧有重力、另一侧没有，或一侧已经运行两秒、另一侧只运行一秒，那么长度差可能来自题目而不是算法。本章不加入重力、碰撞或外力，避免这些因素掩盖求解差别；这是受控实验，不是完整布料仿真。

本节小结：公平比较先复制同一道题，再只替换求解器，并公开所有固定参数。

8.3 · 运行骨架

共同循环：相同运输时间，不同内部工作

共同循环只约定外层运输时间，不假装内部运算相同。三种方法都在共享 UI 的一次更新中推进 \(H=1/60\,\mathrm s\)。但“相同时间”不等于“相同运算”。质量弹簧按力、加速度、速度、位置的顺序积分；PBD 与 XPBD 先预测位置，再投影，最后从真实位置变化重建速度。

\[ \text{预测： }\mathbf p^*=\mathbf p+H\mathbf v,\qquad \text{重建： }\mathbf v'=\frac{\mathbf p'-\mathbf p}{H}. \]

对 PBD 与 XPBD，投影前的预测位置和投影前的旧位置都必须保存。若速度一直没有写回，动能读数会错误地停留在初值；若用预测速度代替重建速度，又会漏掉约束对运动的冲量效果。当前 Python physics/common/simulation.py 正是在每个实际子步保存旧位置、求解约束，再除以实际步长重建速度。

外层与内层。外层由共享 UI 的固定 \(1/60\,\mathrm s\) 累加器驱动。本章竞赛 Demo 每条 PBD/XPBD 运行使用一个实际子步，所以 \(h=H\)；子步 Demo 则在一个外层更新内执行多个实际子步。不能把浏览器 RAF 的到达时刻直接当作积分步长。

顺序伪代码。

把同一初值复制成三条独立运行
每次固定外层更新 H = 1/60：
    质量弹簧：力 -> 加速度 -> 速度 -> 位置
    PBD/XPBD：保存旧位置 -> 用 H 预测 -> 投影 -> 重建速度
    测量三条运行的长度、误差和动能

可复现性。点击重置会恢复共同初值；改变公共质量、目标长度或迭代数会从同一初值重新构造全部运行。因此读数不是三段互相衔接的历史，而是三道同题答卷。

本节小结：共同循环保证相同模拟时间，内部顺序则如实反映每种方法的工作。

8.4 · 观察响应

拉伸响应：长度、速度与误差一起看

solver-race 并排显示质量弹簧、PBD、XPBD 的两质点弹簧。默认初值为 \(m=1\,\mathrm{kg}\)、\(L_0=2\,\mathrm m\)、两端初始速度大小 \(0.6\,\mathrm{m/s}\)。播放、单步和重置都可用；画布只画三条运行，不把某一侧的结果复制给另一侧。

第一步就能区分三种路径。质量弹簧先算当前伸长 \(L-L_0=1\,\mathrm m\)，相对伸长速度为 \(1.2\,\mathrm{m/s}\)，劲度系数 \(k=120\,\mathrm{N/m}\)。共享核心返回沿 \(a\to b\) 方向作用于 b 端的带符号内力 springForce(1,1.2,120,0)=-120，所以 a 端受到相反方向的 \(120\,\mathrm N\) 内力。等质量两端加速度相反，更新后的速度为 \(v_a'=1.4\,\mathrm{m/s}\)、\(v_b'=-1.4\,\mathrm{m/s}\)；半隐式欧拉用更新后的速度推进位置，弹簧缩短，长度约为 \(2.95333\,\mathrm m\)。

\[ a_a=120\,\mathrm{m/s^2},\quad a_b=-120\,\mathrm{m/s^2},\quad L'=3-2.8H\approx2.953333\,\mathrm m. \]

PBD 先把位置预测到 \(3.02\,\mathrm m\)，随后全刚度投影到 \(2\,\mathrm m\)。从旧位置到新位置重建速度，两端速度变为 \(30\,\mathrm{m/s}\) 与 \(-30\,\mathrm{m/s}\)。这不是“弹簧力恰好为 \(1800\,\mathrm N\)”，而是位置投影在一步内产生的速度变化。

XPBD 使用正柔度，第一步不会精确压到目标长度。多次同子步迭代会继续修正，但最终仍可保留正柔度对应的偏差。竞赛 Demo 的 lambda 每次外层更新开始清零，因为只有一个实际子步；迭代之间必须继承返回值。

读图顺序。先看最终长度是否回到 \(L_0\)，再看最大相对距离误差是否在整个播放过程中累积，最后看动能是否与重建速度一致。只凭“线画得更像弹簧”不能判断数值正确。

本节小结：拉伸响应是长度、速度、约束误差与能量共同描述的轨迹，不是单一截图。

质量弹簧、PBD、XPBD 三路同题竞赛

浏览器概念实验；默认暂停。三条两粒子弹簧使用相同初值、公共质量与目标长度；质量弹簧固定 k=120 并使用稳定力积分，PBD/XPBD 的迭代旋钮只影响投影。显示最终长度、最大相对距离误差、实际动能与质量弹簧单列的弹性势能。

8.5 · 参数边界

参数不可直接互换：力刚度、投影比例与柔度

三个旋钮看起来都在说“软硬”，却属于不同层次。质量弹簧的 \(k\) 进入胡克定律，单位是 \(\mathrm{N/m}\)；PBD 的投影刚度 \(s\in[0,1]\) 只缩放单次位置修正；XPBD 的柔度 \(\alpha\) 进入离散约束方程，并与实际子步长组合。

\[ F=-k(L-L_0),\qquad \Delta\mathbf p_{\mathrm{corr}}=s\frac{C}{w_a+w_b}\mathbf n,\qquad \tilde{\alpha}=\frac{\alpha}{h^2}. \]

本章 PBD 始终取 \(s=1\)，不做“为了公平而偷偷调低”的投影。竞赛中固定 \(k=120\,\mathrm{N/m}\) 与 \(\alpha=0.01\,\mathrm{s^2/kg}\)，只允许迭代数影响 PBD/XPBD 的投影轮数。这样可以看到不同数值路径，但不能据此宣布某一个材料参数等价于另一个。

稳定步长。两端都可运动时，相对坐标使用约化质量 \(\mu=m/2\)，不能把一端固定的单质点步长直接套过来。共享核心的稳定步长函数返回 \(H_{\mathrm{stable}}=2/\sqrt{k/\mu}\)。本实验要求

\[ \mu=\frac m2,\qquad H=1/60\,\mathrm s<H_{\mathrm{stable}}=2\sqrt{\frac{m}{240}}\,\mathrm s. \]

默认 \(m=1\,\mathrm{kg}\) 时约化质量为 \(0.5\,\mathrm{kg}\)，稳定步长约为 \(0.09129\,\mathrm s\)，当前步长明显更小。控件上限 \(m=2\,\mathrm{kg}\) 时约为 \(0.12910\,\mathrm s\)，仍满足条件。这个检查针对显式半隐式积分，不证明 PBD 或 XPBD 的所有耦合系统都稳定。

零柔度不是材料弹簧。当 \(\alpha=0\) 时，XPBD 的距离增量公式退化为全刚度 PBD 投影；这验证接口关系，不意味着真实材料没有弹性。正柔度下，\(\alpha\) 与 \(k\) 的映射还依赖约束函数、单位、时间离散与逆质量。

本节小结：先辨认参数所属方程，再比较结果；不能把三个“软硬旋钮”当成同一进制。

8.6 · 计算预算

迭代与子步：两种增加计算的方式

迭代是在同一个实际子步内重复读取最新位置并修正约束；子步是把同一段物理时间切成更短的片段。增加任一项都可能降低误差，但代价与数值含义不同。本章竞赛 Demo 的质量弹簧使用力积分，不消耗 PBD/XPBD 的迭代预算。

对一条独立距离约束，PBD 全刚度投影一次即可满足当前几何；正柔度 XPBD 即使只有一条约束，也要通过迭代逼近离散约束方程。多条约束共享质点时，后一条约束会破坏前一条已满足的长度，因此轮数更重要。当前 Python physics/cloth/xpbd.py 对每条约束保存 lambda，并在每个实际子步开始统一清零。

\[ \lambda^{(s,0)}=0,\qquad \lambda^{(s,k+1)}=\lambda^{(s,k)}+\Delta\lambda^{(s,k)},\qquad \lambda^{(s+1,0)}=0. \]

这里 \(s\) 是实际子步编号，\(k\) 是子步内迭代编号。竞赛 Demo 只有一个子步，所以每次 UI 更新清零一次；子步 Demo 的四条独立运行各自按自己的 \(s\) 次循环，参考运行的八次清零不能与所选运行的清零混用。

公平成本记录。若一次外层更新选择 \(q\) 个子步、每子步 \(r\) 轮，那么一条约束的投影调用数为 \(qr\)。四种方法/子步组合同时运行时，总调用数应按每条运行分别累加，不能把参考运行的额外成本藏起来。

为什么不无限加轮数。有限精度下继续迭代可能只产生极小变化，却仍消耗时间；不收敛的系统还会放大误差。应同时观察长度、误差与调用数，在误差目标和计算预算之间作工程选择。

本节小结：迭代修正当前子步，子步缩短真实步长；两者都不能替代正确的 lambda 生命周期。

8.7 · 能量账本

能量与阻尼：只比较可定义的量

三种方法都能给出位置和重建速度，因此可以用同一公式计算两质点的动能：

\[ K=\frac12m\lVert\mathbf v_a\rVert^2+\frac12m\lVert\mathbf v_b\rVert^2 =\frac12m\lVert\mathbf v\rVert^2, \]

两端等质量且速度大小相同时，可简写为 \(K=\frac12m\lVert\mathbf v\rVert^2\)。其中 \(\mathbf v\) 表示任一端点的速度向量；两端速度大小相同只是本对称算例的性质。竞赛 Demo 直接读取每条运行的实际速度，不用位置误差或虚构力估算动能。动能变化是 \(K(t)-K(0)\)，可正可负，不自动等于“算法损失的能量”。

质量弹簧还单独显示总机械能，并把弹性势能列入账本：

\[ U=\frac12k(L-L_0)^2. \]

总机械能写作 \(E_{\mathrm{ms}}=K+U\)，只属于这条显式质量弹簧运行。

为什么单独标注。PBD/XPBD 的位置投影没有显式积分弹簧势能，正柔度约束也不提供本章已经推导完成的统一机械能定义。把三种方法的 \(K+U\) 都打印出来并排名，会把不同模型混成一个看似公平的能量指标。

无阻尼约定。为隔离求解差别，本实验不启用额外阻尼；质量弹簧的弹簧阻尼系数取零。位置投影造成的速度变化仍会改变动能，它是数值路径的一部分，不应被描述成虚构的黏性阻尼。当前 Python 公共循环另有指数阻尼，默认系数为 \(0.01\)，所以不能把浏览器无阻尼轨迹直接当作 Python 轨迹。

能量不替代误差。动能很大可能来自约束修正，动能很小也可能只是两侧几乎不动。即使总机械能看起来稳定，也可能仍偏离目标长度。必须把能量、最终长度和约束误差一起读。

本节小结：共同动能来自真实速度；质量弹簧势能单列，不用不完整能量账本判断赢家。

8.8 · 评分尺

约束误差：同时记录最终偏差与最坏时刻

最终长度只描述最后一帧。弹簧可能先冲过目标，再在下一帧碰巧回到目标，因此本章同时保存整个播放期间的最大相对距离误差：

\[ E=\max_t\frac{|L(t)-L_0|}{L_0}. \]

每条运行都从相同的 \(1.5L_0\) 出发，所以初始相对误差为 \(0.5\)。每次更新后，用当前误差更新该运行的历史最大值。三条运行分开累计，不能把 PBD 的零误差借给 XPBD。

误差条使用同一标尺。子步 Demo 同时画 PBD 与 XPBD 的所选、参考相对约束误差。四根条从同一基线出发，使用同一最大刻度；若各自归一化，短条会看起来同样严重，破坏视觉比较。328×180 画布保留文字与条形区域，所有坐标都限制在画布内。

长度差不是误差。所选与参考的绝对长度差衡量时间步敏感性，相对于目标长度的误差衡量约束满足程度。一个运行可以与参考很接近，但两者都偏离 \(L_0\)；另一个运行可能更接近目标，却对子步数更敏感。因此两种指标必须分别报告。

零目标长度不可除。本实验目标长度范围为 \(1\) 到 \(3\,\mathrm m\)，避免相对误差分母为零。两点重合时单位方向没有定义，实现会拒绝退化几何，而不是输出一个假零误差。

非有限值不裁剪。若位置、速度、lambda 或读数出现 NaN 或 Infinity，Demo 立即暂停并提示重置。显示“0”或把数值夹到范围里，只会把真实数值故障藏起来。

本节小结：最终误差、历史最大误差与子步长度差回答不同问题，应使用同一标尺分别呈现。

8.9 · 时间步实验

时间步变化：相同总时间下检验子步不变性

substep-invariance 固定总模拟时间 \(T=1\,\mathrm s\)，即 60 次共享界面更新。每次更新运输 \(H=1/60\,\mathrm s\)；选择 \(q\) 个实际子步时，每个子步为

\[ h=\frac{H}{q}=\frac{1}{60q}\,\mathrm s, \qquad qh=H. \]

PBD 与 XPBD 各有两条独立运行：一条使用控件选择的 \(q=1,2,4,8\)，另一条始终使用固定的 \(q=8\) 作为参考。四条运行从相同位置、速度、质量和目标长度出发，播放相同 60 次更新。改变柔度或迭代数会同时重建四条运行，不让参考偷偷保留旧参数。

核心数值检验。另有一个直接调用共享核心的 Node 测试：正柔度 \(\alpha=0.01\)，两质点从 \(0\) 与 \(3\) 出发，目标长度 \(2\)，每个子步 40 轮。比较一个 \(h=1/60\,\mathrm s\) 子步与两个 \(h=1/120\,\mathrm s\) 子步，并在每个实际子步开始把 lambda 置零。

\[ L_{1/60}\approx2.947368421\,\mathrm m,\qquad L_{2\times1/120}\approx2.972790392\,\mathrm m, \] \[ |L_{1/60}-L_{2\times1/120}|\approx0.025421971\,\mathrm m<0.03\,\mathrm m. \]

这里 \(0.03\,\mathrm m\) 是本章为指定简单算例设定的教学容限，不是所有系统的精度保证。零柔度时 XPBD 退化为 PBD，一条独立距离约束可能很快得到相同几何；但正柔度、多条耦合约束、非线性梯度或有限迭代会留下差异。PBD 不要求通过这个 XPBD 容限。

为什么不是逐位相同。每轮方向与梯度都随位置变化；有限轮数可能尚未收敛；速度重建把位置离散误差带入下一步；计算顺序和浮点舍入也会改变路径。更多子步通常帮助接近连续极限，却不保证任意系统误差单调下降。

本节小结：固定总时间、材料和初值，只改实际子步；用明确容限检查近似一致性，不宣称普遍精确不变。

相同总时间下的所选与参考子步比较

浏览器概念实验；默认暂停。PBD 与 XPBD 各自独立运行所选子步和固定八子步参考，总模拟时间均为一秒。调节子步数、迭代与正柔度，比较四条最终长度、所选与参考绝对长度差和同标尺约束误差条。

8.10 · 工程权衡

性能指标：误差、调用数与能耗分开记账

“更快”可以是每次更新更少运算，也可以是达到同一误差所需总运算更少。只比较一帧耗时不公平：某方法可能单步便宜，却需要更多子步或轮数才能满足约束。本章提供可核对的结构性成本，不把运行时间当成稳定成绩。

对一条约束，若每子步 \(r\) 轮、每外层更新 \(q\) 子步，则投影调用数为 \(qr\)。若系统有 \(n_c\) 条约束，一次完整 Gauss–Seidel 扫描通常访问 \(n_c\) 条，预算约为 \(qrn_c\) 次约束修正。XPBD 每次还增加有效柔度与乘子更新，PBD 使用固定投影比例，质量弹簧则计算力和积分。

\[ N_{\mathrm{projection}}=qrn_c,\qquad N_{\mathrm{update}}=60N_{\mathrm{projection}}\quad(T=1\,\mathrm s). \]

内存与状态。XPBD 需要为每条约束保存 lambda，并在每个实际子步清零；PBD 不需要这套约束乘子数组。质量弹簧需要力、速度和位置更新。约束越多、耦合越强，乘子管理与扫描顺序越值得检查。

误差预算是第一位。先定义可接受的最大相对约束误差，再比较达到该误差的调用数。若一个算法误差更小但能量偏差很大，或对子步极其敏感，就不能仅凭调用少宣布胜出。真实应用还应测量 CPU/GPU 时间、内存带宽和并行度，本章小算例不提供这些硬件数据。

当前实现边界。Python 布料使用 float32 张量，浏览器共享核心使用 JavaScript 双精度；两者的约束集合、积分器和求解顺序不同。跨语言比较应看概念与趋势，不承诺相同耗时或逐位相同的结果。

本节小结：先达到误差目标，再比较计算预算和状态成本；小 Demo 的帧时间不是通用性能结论。

8.11 · 动手核算

算例：把三种第一步写成可检查的数

取 \(m=1\,\mathrm{kg}\)、\(L_0=2\,\mathrm m\)、\(k=120\,\mathrm{N/m}\)、\(\alpha=0.01\,\mathrm{s^2/kg}\)、\(H=1/60\,\mathrm s\)。初始位置为 \(-1.5\) 与 \(1.5\)，速度为 \(-0.6\) 与 \(0.6\)，所以初始长度为 \(3\,\mathrm m\)，初始动能为 \(0.36\,\mathrm J\)。

质量弹簧。当前伸长 \(L-L_0=1\,\mathrm m\)，相对伸长速度为 \(1.2\,\mathrm{m/s}\)，所以 springForce(1,1.2,120,0)=-120。这个负号表示 b 端受力沿 \(a\to b\) 的反方向；等质量 a 端因此受到正向恢复力，两端加速度为 \(120\) 与 \(-120\,\mathrm{m/s^2}\)。更新速度后位置使用新速度：

\[ v_a'=-0.6+120H=1.4,\quad v_b'=0.6-120H=-1.4,\quad p_a'=-1.5+1.4H,\quad p_b'=1.5-1.4H, \] \[ L'=3-2.8H\approx2.953333\,\mathrm m,\quad K'=1.96\,\mathrm J,\quad U'\approx54.530667\,\mathrm J. \]

PBD。预测长度为 \(3+1.2H=3.02\,\mathrm m\)。等逆质量 \(w_a=w_b=1\) 时，一次全刚度投影把两端各移 \(0.51\,\mathrm m\)，长度回到 \(2\,\mathrm m\)，左端重建速度为 \(+30\,\mathrm{m/s}\)、右端为 \(-30\,\mathrm{m/s}\)，动能为 \(900\,\mathrm J\)。这个巨大动能来自一步投影，不应解释为弹簧在这段时间内真的做了那么多功。

XPBD。有效柔度为 \(\tilde{\alpha}=0.01/(1/60)^2=36\)。先预测位置，使当前误差为 \(C=1.02\,\mathrm m\)。从 lambda 为零开始，第一轮 \(\Delta\lambda=-1.02/(2+36)\approx-0.026842105\)，长度约为 \(2.966315789\,\mathrm m\)。本算例随后很快接近同一个离散平衡点，但一般耦合系统仍要检查迭代是否充分，不能把第一轮数字冒充所有系统的最终值。

自测。点击单步后核对三个长度、三个实际动能和质量弹簧的约 \(54.531\,\mathrm J\) 弹性势能；再把迭代数从 8 改为 1，PBD 的一条独立约束仍精确满足，XPBD 与质量弹簧的第一步则不应因旋钮改变。

本节小结：可手算的第一步能暴露速度未重建、lambda 被清零或柔度单位混淆等错误。

8.12 · 方法选择

决策表：按目标选择，不设通用冠军

没有一种方法在所有题目、硬件和误差目标下都最好。选择时应先问需要的是显式材料力、位置约束满足，还是对时间步更稳健的软约束响应。

需求优先考虑必须核对
弹簧力、真实阻尼、与势能直接对应的振动质量弹簧显式积分稳定步长；刚度不能随意增大
快速满足硬距离约束、实现简单PBD位置投影不等于显式力；记录速度重建与耦合误差
用统一柔度描述软硬，并希望子步变化更温和XPBD有效柔度、每条约束 lambda、每子步清零与足够迭代
刚体碰撞与接触碰撞求解器或混合系统接触、摩擦、恢复与法向方向，不能套用本章无碰撞弹簧结论
相同总时间下比较时间步敏感性所选/参考子步实验初值、材料、总时间一致；使用明确容限，不要求逐位相同

质量弹簧适合什么。当你确实需要胡克定律、弹簧阻尼或显式能量时，它最直观。较硬的弹簧会限制稳定步长；高质量网格还可能需要更小步长或隐式方法。本章只覆盖两质点显式积分，不把结论外推到任意网格。

PBD 适合什么。当约束主要是“不要拉得太长”，位置投影简单且容易满足硬约束。它可能快速改变速度并产生数值能耗，多约束耦合时还需要合理扫描顺序。投影刚度 \(s\) 是修正比例，不是材料参数。

XPBD 适合什么。当你需要用柔度控制允许的变形，并愿意维护乘子状态时，它提供更清晰的离散材料接口。正柔度允许残差；子步不变性仍是近似性质。没有正确 lambda 生命周期，XPBD 的名称再完整也不会自动变好。

混合方案。实际系统常把力积分、位置约束、碰撞和阻尼组合。此时“公平”首先意味着如实记录每一部分的顺序、时间步与能量定义，而不是把不同模型压缩成一个分数。

本节小结：根据物理模型、误差目标和计算预算选择方法，并公开方法的近似边界。

8.13 · 实现检查

伪代码与调试：让每条运行都能独立复现

本节的伪代码与调试表把前面的性能指标和决策表变成检查动作。参数不可直接互换，有限迭代与非线性几何也不保证逐位相同。

竞赛骨架。三条运行独立克隆，质量弹簧不消耗迭代预算；XPBD 在唯一实际子步开始清零：

质量弹簧、PBD、XPBD = 各自复制同一初值
每次外层更新 H = 1/60：
    检查 H < stableSpringStep(k, m/2)
    质量弹簧 = 力积分(质量弹簧, k, m, H)       # 不使用投影迭代
    旧PBD位置 = 复制(PBD位置)
    PBD = 预测(PBD, H)
    重复 iterations 次：
        投影结果 = RTPhysics.projectDistance(PBD.a, PBD.b, L0, 1)
        写回投影结果.a 和投影结果.b
    PBD速度 = (PBD位置 - 旧PBD位置) / H
    对 XPBD 执行相同的预测、投影和重建
    XPBD.lambda = 0                             # 每个实际子步一次
    重复 iterations 次：
        软约束结果 = RTPhysics.projectDistanceXPBD(
            XPBD.a, XPBD.b, L0, alpha, H, XPBD.lambda)
        写回位置和软约束结果.lambda
    重建 XPBD 速度；测量全部运行

子步骨架。四条运行各自重置 lambda，参考运行始终使用八个子步：

每次外层更新 H = 1/60：
    对方法 in [PBD, XPBD]：
        对组 in [所选(q), 参考(8)]：
            h = H / 组.子步数
            对每个实际子步：
                若方法为 XPBD：运行.lambda = 0
                保存旧位置；用 h 预测
                重复 iterations 次：用当前 h 和 lambda 投影
                用 h 重建速度
            测量最终长度和最大相对误差
    time += H                                    # 不是 q * H
症状优先检查最小动作
三条曲线初值不同对象被共享，目标长度只改了一侧深复制每条运行，用同一构造函数重建
质量弹簧随迭代数改变把投影轮数误用于力积分固定每外层更新一次力积分
动能一直是初值PBD/XPBD 投影后没有重建速度用投影后位置减旧位置再除以实际步长
XPBD 每轮都从零开始lambda 在子步内被误清零同子步继承返回值，只在下个实际子步清零
子步改变后总时间变了时间增量写成 qH核对所有运行 \(time\leftarrow time+H\)
能量看起来普遍最优把 PBD/XPBD 也套上质量弹簧势能共同只比动能；质量弹簧总机械能单列
NaN / Infinity 被画成有限值裁剪掩盖了退化几何或坏参数暂停、显示重置提示，不编造读数

当前 Python 实现。physics/cloth/mass_spring.py 用结构、剪切、弯曲三类距离弹簧的力积分；physics/cloth/pbd.py 按约束类型使用投影刚度并迭代；physics/cloth/xpbd.py 保存各类柔度与 lambda，在每个子步开始清零。physics/common/simulation.py 默认 fixed_dt=1/120、substeps=2，实际子步为 \(1/240\,\mathrm s\)，并包含重力、指数阻尼和固定点处理。

浏览器概念实验。两个 Demo 调用真实 book/assets/physics-core.js 的 stableSpringStep、projectDistance、projectDistanceXPBD 与 springForce，但只研究两质点、无碰撞、无额外阻尼的教学模型。JavaScript 双精度与 Python float32、不同约束集合和积分路径意味着不能逐位对照。

有限迭代、非线性距离几何、阻尼、能量定义与参数映射共同限制了结论。本章没有通用赢家，只有对指定题目更合适的工具。

本章小结：公平比较来自共同初值与循环，可靠结论来自真实速度、独立能量账本、正确乘子生命周期和明确的近似容限。
